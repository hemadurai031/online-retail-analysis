# Online Retail Sales Analysis

## 📌 Project Overview

This project analyzes online retail transaction data to understand sales patterns, customer purchasing behavior, product performance, and country-wise revenue.

## 🎯 Objectives

- Clean and preprocess the retail transaction data
- Analyze sales and purchasing patterns
- Identify top-performing products
- Analyze country-wise sales
- Understand monthly sales trends
- Generate meaningful business insights

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 📊 Analysis Performed

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Descriptive Statistics
- Sales Trend Analysis
- Country-wise Sales Analysis
- Product Analysis
- Data Visualization

## 📁 Dataset

Online Retail transaction dataset containing sales transactions from 2010–2011.

## 📈 Key Visualizations

The project includes:

- Monthly Sales Trend
- Top Countries by Sales
- Product and Quantity Analysis
- Sales Distribution
- Year-wise Monthly Sales Heatmap

## 💡 Key Insights

Insights from the analysis are documented in the project notebook.
